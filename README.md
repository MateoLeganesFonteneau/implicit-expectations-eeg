# Implicit expectations: EEG analysis code

Analysis and figure-generation code for the final **N = 43** version of the
reward Pavlovian-conditioning manuscript. The repository covers the ERP,
time-frequency, cluster-permutation, and FRN outcome analyses reported in the
paper.

The repository also contains the MATLAB awareness-categorization analysis and
its trial-level input data. Cleaned EEG epochs are not included.

## Awareness categorization

`awareness/categorize_awareness.m` applies the Bayesian Awareness
Categorization Technique to all available trials for each participant. It reads
the included `awareness/raw_data/contingency_data_EEG.mat` file and writes the
participant-level classifications to `awareness/outputs/`. See
`awareness/README.md` for the model settings and category coding.

## Analysis digest

| Stage | Script | Analysis | Principal output |
|---|---|---|---|
| 1 | `analysis/01_compute_erp.py` | Subject ERPs, grand averages, windowed repeated-measures ANOVAs | ERP summary/statistics files, wide tables, ANOVA table with partial eta-squared |
| 2 | `analysis/02_cluster_erp.py` | One-dimensional cluster-permutation tests on ERP contrasts | `erp_clusters.pkl` |
| 3 | `analysis/03_plot_erp.py` | P3, CNV, SPN, and FRN composite ERP figure | `GrandAverage_P3_CNVSPN_FRN_byHalf_clusters.png` |
| 4 | `analysis/04_compute_tfr.py` | Single-trial Morlet time-frequency decomposition and dB baseline normalization | Cached subject-by-condition TFR files |
| 5 | `analysis/05_cluster_tfr.py` | CNV and FRN time-frequency cluster-permutation tests | Cluster figures and masks |
| 6 | `analysis/06_cluster_cnv_interaction.py` | CNV Condition x Half difference-of-differences cluster test | CNV interaction mask and diagnostic figure |
| 7 | `analysis/07_plot_cnv_tfr.py` | Anticipatory time-frequency composite | `CNV_TF_composite.png` |
| 8 | `analysis/08_plot_frn_tfr.py` | Feedback time-frequency composite | `FRN_TF_3way_composite.png` |
| 9 | `analysis/09_frn_reward_analysis.py` | FRN CS Type x Outcome x Half ANOVA and corrected follow-ups | ANOVA, marginal-mean and post-hoc tables; FRN figures |

### ERP definitions

- **P3:** CPz/Pz, 200-500 ms after cue onset.
- **CNV:** FCz/Cz, 300-700 ms after the post-cue fixation onset.
- **SPN:** FCz/Cz, 900-1000 ms after fixation onset, using the CNV epochs.
- **FRN:** Fz/FCz, 200-300 ms after feedback onset.
- Windowed tests use within-participant repeated-measures ANOVAs. The exported
  ANOVA tables include partial eta-squared, calculated from the unrounded F and
  degrees of freedom.
- ERP waveform inference uses two-sided, one-sample cluster-permutation tests
  on within-participant contrasts, with 1,000 permutations and seed 42.

### Time-frequency definitions

- Morlet frequencies: 2 to 29.5 Hz in 0.5-Hz steps.
- Number of cycles: frequency / 2.
- Baseline: -300 to 0 ms, with the first 10 ms excluded for numerical safety.
- Baseline-normalized power is converted to dB.
- Cluster inference uses joint time-frequency adjacency, two-sided tests,
  1,000 permutations, and seed 42.
- The CNV analyses test CS+ minus CS- within each half, collapsed across halves,
  and the Condition x Half difference of differences.
- The FRN analyses test reward minus no reward separately by cue type and task
  half, as well as the cue-type interaction.

## Participant selection

The final exclusion list is defined once in `analysis/config.py` and is shared
by every analysis. It includes participant 1028, yielding the final N = 43 EEG
sample used in the manuscript.

## Expected inputs

Set `IMPLICIT_EXPECT_EPOCHS_DIR` to the directory containing cleaned,
condition-specific MNE Epochs files. Filenames follow this pattern:

```text
sub-<ID>_<condition>_<half>-epo.fif
```

Conditions used by the scripts include:

```text
CS+ presentation / CS- presentation
CNV+ fixation / CNV- fixation
FRN+ Expected / FRN+ Unexpected
FRN- Expected / FRN- Unexpected
```

If the FRN follow-up epochs are stored separately, set
`IMPLICIT_EXPECT_FRN_EPOCHS_DIR`. Set `IMPLICIT_EXPECT_OUTPUT_DIR` to choose the
output directory. TFR caches default to `<epochs>/tfr_dB`; override this with
`IMPLICIT_EXPECT_TFR_DIR` if necessary.

## Installation

Python 3.10 or later is recommended.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Running the pipeline

```bash
export IMPLICIT_EXPECT_EPOCHS_DIR="/path/to/cleaned/epochs"
export IMPLICIT_EXPECT_OUTPUT_DIR="/path/to/analysis/outputs"

python analysis/01_compute_erp.py
python analysis/02_cluster_erp.py
python analysis/03_plot_erp.py

python analysis/04_compute_tfr.py
python analysis/05_cluster_tfr.py
python analysis/06_cluster_cnv_interaction.py
python analysis/07_plot_cnv_tfr.py
python analysis/08_plot_frn_tfr.py

python analysis/09_frn_reward_analysis.py
```

The ERP and time-frequency branches are independent until figure generation.
Scripts 3, 7, and 8 expect the summaries or cluster masks generated by their
preceding stages.

## Repository-release changes

The scientific contrasts, channels, analysis windows, baseline procedure, and
permutation counts match the final manuscript pipeline. For the repository
release, machine-specific paths were replaced with environment variables, the
final participant exclusion list was centralized, a fixed seed was added to
the time-frequency permutation calls, and partial eta-squared was added to the
saved ANOVA tables.
