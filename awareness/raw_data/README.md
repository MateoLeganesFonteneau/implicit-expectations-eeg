# Trial-level awareness data

`contingency_data_EEG.mat` is the analysis input used by
`../categorize_awareness.m`. It contains a single numeric matrix named `data`
with 13,580 trial-level rows and three columns:

1. study participant ID;
2. accuracy, coded 0 or 1;
3. stimulus type, coded 0 or 1.

The file contains 57 study IDs before the exclusions defined in the analysis
script. It contains no participant names or other direct identifiers.
